    Clave de YouTube

    Para ordenar por fecha de publicación, visualizaciones o duración hace falta esta clave.

    Con una clave gratuita de la API de YouTube, la app muestra la duración, las visualizaciones y la fecha de publicación de cada vídeo, y puede ordenar por esos datos.

    1. Entra en console.cloud.google.com con tu cuenta de Google y crea un proyecto.
    2. En «APIs y servicios» → «Biblioteca», busca YouTube Data API v3 y pulsa Habilitar.
    3. En «Credenciales» → «Crear credenciales» → «Clave de API», copia la clave.
    4. Recomendado: en la clave, limita los sitios web a la dirección de tu app (por ejemplo, https://TU-USUARIO.github.io/*).

    Se guarda solo en este navegador y no se incluye al exportar.

    Enlaces para extraer vídeos

    Webs que sacan los enlaces de los vídeos de una lista de YouTube. Copia los enlaces que te den y pégalos todos juntos en «Añadir a la lista». Se abren en una pestaña nueva.

    Para usar tus propias listas de YouTube

    Pon la lista como Pública, no como Privada: si es privada, YouTube no deja leerla, ni a estas webs ni a la Videoteca. En la app de YouTube: Tú → Listas → abre la lista → lápiz (Editar) → Privacidad → Pública.
